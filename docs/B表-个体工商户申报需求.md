## B 表定位

B 表 = 个人所得税基础信息表（B表），面向**个体工商户**经营所得申报。和 A 表（雇员）共用同一套申报流程，不同的是计税逻辑和字段。

## 与 A 表的核心差异

| 对比维度 | A 表 | B 表 |
|----------|------|------|
| 适用人群 | 雇员（有扣缴义务人） | 个体工商户 / 自由职业者 |
| 任职受雇从业信息 | 必填 | **不填** |
| 被投资单位信息 | 不填 | **填自己的个体工商户名称 + 信用代码** |
| 申报周期 | 按月 | **按季度**：1月/4月/7月/10月，一年四次 |
| 是否有工资 | 有 | **无** |
| 计税逻辑 | 工资 - 社保 - 专项扣除 - 起征点 | 收入 - 成本(含房租) - 社保 - 专项扣除 - 亏损 |

## 计税公式

```
应纳税所得额 = 年收入 - 年成本 - 年社保 - 基本扣除(60000) - 专项附加扣除 - 弥补以前年度亏损
应纳个税额 = 应纳税所得额 × 适用税率 - 速算扣除数
季度预缴税额 = 年税额 ÷ 4
```

税率表：经营所得 5%-35% 五级超额累进（`tax_rate_tables.json` → `business.brackets`）
