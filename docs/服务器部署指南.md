# 财务 RAG Agent · 服务器部署指南

> 将项目从本地笔记本部署到云服务器，供公网访问。

---

## 一、当前硬件 vs 服务器需求

### 你的本地环境

| 硬件 | 规格 | 承担任务 |
|------|------|---------|
| GPU | RTX 4060 8GB VRAM | BGE-M3 嵌入 + BGE-Reranker-v2-m3 精排 |
| RAM | 16GB | Python 进程 + Qdrant + 前端构建 |
| 磁盘 | NVMe SSD | 模型文件 (~5GB) + 向量数据 + 源码 |
| 网络 | 本地 127.0.0.1 | 无公网访问 |

### 云服务器最低配置

| 硬件 | 最低 | 推荐 | 说明 |
|------|------|------|------|
| **GPU 显存** | **8GB** | 16GB | BGE-M3 fp16 (~2GB) + Reranker (~2GB) + 峰值余量 |
| **CPU** | 4 核 | 8 核 | Qdrant + FastAPI + 向量计算 |
| **内存** | **16GB** | 32GB | 模型加载 + Qdrant 容器 + Python 进程 |
| **系统盘** | 50GB | 100GB | 模型文件 ~5GB + Docker + 系统 |
| **数据盘** | 50GB | 100GB | 向量数据 (~1GB) + 源码 + 日志 |
| **带宽** | 5Mbps | 10Mbps | SSE 流式响应对带宽有要求 |

## 二、国内云服务器选型（最关键的决策）

### 核心权衡：GPU 成本

你的系统需要 GPU 做两件事：

| 任务 | GPU 必要性 | 能省吗 |
|------|:--:|------|
| BGE-M3 向量嵌入 | **必须** | ❌ 需 GPU，fp16 推理 ~2GB |
| BGE-Reranker-v2-m3 精排 | **必须** | ❌ Cross-encoder 推理 ~2GB |
| DeepSeek LLM | 不需要 | ✅ 走 API，无需本地 GPU |

### 🏆 方案一：AutoDL（毕设首选，最省钱）

**为什么选它**：
- 国内最大的 GPU 算力租赁平台，学生友好
- 按**小时**计费，随用随开，关机只收极少存储费
- RTX 4060 8GB 和你的本地环境**完全一致**，无兼容问题
- 预装 CUDA 12.1 + PyTorch 2.x + Conda，开箱即用
- 内置 JupyterLab + SSH + 文件传输，部署调试超方便
- 支持 Docker（需在控制台开启容器特权模式）

**怎么买**：
1. 打开 [autodl.com](https://www.autodl.com) 注册（微信/手机号）
2. 充值 ¥50-100（够用一周）
3. 筛选条件：GPU → RTX 4060 / RTX 3060 | 地区 → 北京/上海/广州
4. 镜像：选 "PyTorch 2.x + CUDA 12.1" 官方镜像
5. 创建实例 → 等待 2 分钟分配

**费用估算**：

| 场景 | 使用时长 | 费用 |
|------|:--:|-----|
| 初次部署 + 嵌入数据 | ~2 小时 | ¥2-3 |
| 答辩当天高强度使用 | ~8 小时 | ¥7-12 |
| 一星期反复调试 | ~50 小时 | ¥40-75 |
| 关机存储（数据保留） | 按天 | ¥0.5-1/天 |

> 💡 **省钱技巧**：不需要时在网页端点"关机"（非"销毁"），只收磁盘费。下次开机继续用，数据不丢。

5. 系统盘：100GB ESSD
6. 安全组：放行 80/443/8000 端口

**怎么买（腾讯云 CVM）**：

2. 计费模式选「竞价实例」
3. 机型：GPU 实例 → GN7（T4 16GB）
4. 镜像：Ubuntu 22.04
5. 安全组：放行 80/443/8000

**费用对比**：

| 计费方式 | 月费 | 适合 |

### 下单前必须确认的 8 项

| 检查项 | 必须满足 | 不满足会怎样 |
|--------|:--:|------|
| GPU 显存 ≥ 8GB | ✅ | 模型加载 OOM，服务起不来 |
| 内存 ≥ 16GB | ✅ | Qdrant + Python 吃掉 12GB+，8GB 必 OOM |
| 可装 Docker | ✅ | Qdrant 必须容器 |
| 有公网 IP | ✅ | 无法从浏览器访问 |
| 安全组可放行端口 | ✅ | 防火墙拦截，外部请求 502 |
| CUDA ≥ 11.8 | ✅ | BGE-M3 / FlagEmbedding 不兼容 |
| 出站可访问 api.deepseek.com | ✅ | LLM 调用超时 |
| 出站可访问 hf-mirror.com | ✅ | 模型无法下载（或预上传） |

## 三、环境初始化（以 AutoDL + Ubuntu 为例）

```bash
# 1. 克隆项目
git clone git@github.com:zsy04/finance-rag-agent.git
cd finance-rag-agent

# 2. 安装 Docker + Qdrant
sudo apt update && sudo apt install -y docker.io docker-compose
sudo systemctl start docker
docker compose up -d
# 验证: curl http://localhost:6333/healthz

# 3. 创建 Python 虚拟环境（pip 国内镜像加速）
python3 -m venv backend/venv
source backend/venv/bin/activate
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 4. 设置环境变量
cat > backend/.env << 'EOF'
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
QDRANT_URL=http://localhost:6333
EOF

# 5. 下载模型（国内 HuggingFace 镜像）
export HF_ENDPOINT=https://hf-mirror.com
python -c "from FlagEmbedding import BGEM3FlagModel; BGEM3FlagModel('BAAI/bge-m3', use_fp16=True)"

# 如需手动上传模型（~5GB，避免下载等待）：
# 本地打包: tar -czf models.tar.gz ~/.cache/huggingface/hub/models--BAAI--bge-m3/
# 上传: AutoDL 网页文件管理 → 上传 → 解压到相同路径

# 6. 嵌入数据到 Qdrant
cd scripts
python embed_and_upsert.py
# 等待 15-20 分钟（GPU 编码 2937 chunks）

# 7. 启动后端
cd ..
source backend/venv/bin/activate
nohup python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 > backend.log 2>&1 &
sleep 5
curl http://localhost:8000/health
# 应返回: {"status":"ok"}

# 8. 构建前端 + Nginx 托管
cd frontend
npm install --registry=https://registry.npmmirror.com
npm run build
# dist/ 目录即为静态文件

# 9. 配置 Nginx（参见 §四）
sudo apt install -y nginx
sudo cp ../nginx.conf /etc/nginx/sites-available/finance-rag
sudo ln -sf /etc/nginx/sites-available/finance-rag /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# 10. 验证
curl http://localhost  # 前端页面
curl -N -X POST http://localhost:8000/api/chat \
  -H 'Content-Type: application/json' \
  -d '{"message":"工资8000郑州税多少","thread_id":"test"}'
```

## 四、生产化部署架构

```
用户浏览器
    │
    ▼
┌─────────┐    反向代理     ┌──────────┐    API 调用    ┌──────────────┐
│  Nginx  │ ──────────────→ │ FastAPI  │ ────────────→ │ DeepSeek API │
│ :80/443 │ ←────────────── │ :8000    │               │ (公网)       │
│         │                 │          │               └──────────────┘
│ 托管前端 │                 │ Agent    │
│ dist/    │                 │ + RAG    │
└─────────┘                 │ + Tools  │
                             └────┬─────┘
                                  │ gRPC
                                  ▼
                           ┌──────────┐
                           │ Qdrant   │
                           │ :6333    │
                           │ (Docker) │
                           └──────────┘
```

### Nginx 配置模板

```nginx
server {
    listen 80;
    server_name your-domain.com;  # 或公网 IP

    # 前端静态文件
    root /path/to/finance-rag-agent/frontend/dist;
    index index.html;

    # SPA 路由（React Router）
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 代理 → FastAPI 后端（SSE 需要特殊配置）
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Connection '';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_buffering off;          # SSE 必须关闭缓冲
        proxy_cache off;
        proxy_read_timeout 300s;      # SSE 长连接
    }

    # 图标/静态资源
    location /icons/ {
        alias /path/to/finance-rag-agent/frontend/public/icons/;
        expires 30d;
    }
}
```

## 六、成本优化技巧

| 技巧 | 省多少 | 怎么做 |
|------|:--:|------|
| **按小时计费 + 用完关机** | 90% | AutoDL：不用时点"关机"（非"销毁"），数据保留。一天只需 ¥0.5 磁盘费 |
| **竞价/抢占实例** | 50-70% | 阿里云/腾讯云选择"竞价实例"，价格是包月的 1/3~1/5 |
| **答辩当天按量付费** | 稳 | 竞价实例可能被回收，答辩当天切到按量付费锁定时段 |
| **模型文件预上传** | 时间 | 本地打包 `models.tar.gz`（~5GB），通过 AutoDL 网页文件管理上传，跳过 HuggingFace 下载 |
| **Qdrant 数据预置** | 时间 | 本地跑好 embed_and_upsert.py，打包 qdrant_data/ 上传，跳过 15 分钟嵌入等待 |
| **前端 CDN + OSS** | 带宽 | 阿里云 OSS + CDN 托管前端 dist/，不占用服务器带宽

## 七、如果不用 GPU 服务器（备选）

**可以**，但检索会非常慢：

| 操作 | GPU 服务器 | CPU-only |
|------|:--:|:--:|
| BGE-M3 嵌入 2937 chunks | 15 分钟 | 2-3 小时 |
| 单次检索（dense+sparse+Reranker） | ~2 秒 | ~30 秒 |
| BGE-Reranker 精排 | ~0.5 秒 | ~8 秒 |

**如果坚持 CPU-only**：改用轻量模型（如 `all-MiniLM-L6-v2`），检索质量会明显下降。不推荐用于毕设答辩。

## 八、快速部署脚本（一键部署到 Ubuntu）

```bash
#!/bin/bash
# deploy.sh — 一键部署脚本（Ubuntu 22.04，适用 AutoDL / 阿里云 / 腾讯云）
set -e

echo "========== 财税助手 · 一键部署 =========="

# 0. 环境检查
command -v docker >/dev/null || { echo "请先安装 Docker"; exit 1; }
command -v python3 >/dev/null || { echo "请先安装 Python 3.10+"; exit 1; }
command -v node >/dev/null || { echo "请先安装 Node.js 22+"; exit 1; }

# AutoDL 用户：启用 Docker
if systemctl is-active --quiet docker 2>/dev/null; then
    echo "Docker 已启动"
else
    sudo systemctl start docker
fi

# 1. 启动 Qdrant
echo "[1/7] 启动 Qdrant..."
docker compose up -d
sleep 3
curl -s http://localhost:6333/healthz > /dev/null || { echo "Qdrant 启动失败"; exit 1; }

# 2. Python 环境（国内镜像加速 pip）
echo "[2/7] 安装 Python 依赖..."
python3 -m venv backend/venv
source backend/venv/bin/activate
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple -q

# 3. 环境变量（需手动填 DeepSeek Key）
if [ ! -f backend/.env ]; then
    read -p "请输入 DeepSeek API Key: " DS_KEY
    cat > backend/.env << EOF
DEEPSEEK_API_KEY=$DS_KEY
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
QDRANT_URL=http://localhost:6333
EOF
fi

# 4. 模型下载（国内镜像）
echo "[3/7] 检查模型文件..."
export HF_ENDPOINT=https://hf-mirror.com
python -c "from FlagEmbedding import BGEM3FlagModel; BGEM3FlagModel('BAAI/bge-m3', use_fp16=True)" 2>/dev/null
echo "模型就绪"

# 5. 嵌入数据
echo "[4/7] 嵌入向量数据（约 15 分钟）..."
COLLECTION_EXISTS=$(curl -s http://localhost:6333/collections | grep -c "finance_knowledge" || true)
if [ "$COLLECTION_EXISTS" -eq 0 ]; then
    cd scripts && python embed_and_upsert.py && cd ..
else
    echo "向量数据已存在，跳过嵌入"
fi

# 6. 启动后端
echo "[5/7] 启动后端..."
nohup python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 > backend.log 2>&1 &
sleep 5
curl -s http://localhost:8000/health > /dev/null || { echo "后端启动失败"; cat backend.log; exit 1; }

# 7. 构建前端 + 启动静态服务
echo "[6/7] 构建前端..."
cd frontend && npm install --registry=https://registry.npmmirror.com -q && npm run build && cd ..

echo "[7/7] 安装 Nginx + 配置..."
sudo apt install -y nginx
# Nginx 配置文件见 §四 nginx.conf 模板
sudo cp nginx.conf /etc/nginx/sites-available/finance-rag
sudo ln -sf /etc/nginx/sites-available/finance-rag /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

echo ""
echo "========== 部署完成 =========="
echo "访问: http://$(curl -s ifconfig.me)"
echo "后端日志: tail -f backend.log"
```
