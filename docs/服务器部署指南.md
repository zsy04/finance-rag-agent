# 财务 RAG Agent · 服务器部署指南

> 将项目从本地笔记本部署到云服务器，供公网访问。

---

## 一、当前硬件 vs 服务器需求

### 你的本地环境

| 硬件 | 规格 | 承担任务 |
|------|------|---------|
| GPU | RTX 4060 8GB VRAM | BGE-M3 嵌入 + BGE-Reranker-v2-m3 精排 |
| RAM | 16GB | Python 进程 + Qdrant + 前端构建 |
| 磁盘 | NVMe SSD | 模型文件 (~5GB) + 向量数据 + 源码 |
| 网络 | 本地 127.0.0.1 | 无公网访问 |

### 云服务器最低配置

| 硬件 | 最低 | 推荐 | 说明 |
|------|------|------|------|
| **GPU 显存** | **8GB** | 16GB | BGE-M3 fp16 (~2GB) + Reranker (~2GB) + 峰值余量 |
| **CPU** | 4 核 | 8 核 | Qdrant + FastAPI + 向量计算 |
| **内存** | **16GB** | 32GB | 模型加载 + Qdrant 容器 + Python 进程 |
| **系统盘** | 50GB | 100GB | 模型文件 ~5GB + Docker + 系统 |
| **数据盘** | 50GB | 100GB | 向量数据 (~1GB) + 源码 + 日志 |
| **带宽** | 5Mbps | 10Mbps | SSE 流式响应对带宽有要求 |

## 二、云服务器选型（最关键的决策）

### 核心权衡：GPU 成本

这是部署的最大成本项。你的系统需要 GPU 做两件事：

| 任务 | GPU 必要性 | 能省吗 |
|------|:--:|------|
| BGE-M3 向量嵌入 | **必须** | ❌ 需 GPU，fp16 推理 ~2GB |
| BGE-Reranker-v2-m3 精排 | **必须** | ❌ Cross-encoder 推理 ~2GB |
| DeepSeek LLM | 不需要 | ✅ 走 API，无需本地 GPU |

### 推荐方案对比

| 方案 | 云厂商 | GPU 型号 | 月费（约） | 适用场景 |
|------|--------|---------|:--:|---------|
| **A. 入门 GPU 云主机** | AutoDL / 恒源云 | RTX 4060/3060 8GB | ¥200-400 | 毕设演示、临时部署 |
| **B. 轻量云 GPU** | 阿里云 ecs.gn6i | T4 16GB | ¥800-1500 | 长期运行、小规模并发 |
| **C. GPU 竞价实例** | 腾讯云 竞价 | T4 16GB | ¥300-600 | 答辩演示（按时长） |
| **D. CPU-only + API** | 任意 | 无 GPU | ¥100-200 | 仅前端静态 + 后端逻辑（RAG 检索走 CPU 极慢） |

### 🏆 毕设推荐：方案 A（AutoDL）

**理由**：
1. 按量计费，答辩前后租几天即可
2. RTX 4060 8GB 够用，和你本地一致
3. 预装 CUDA + PyTorch，省去环境配置
4. 支持 Docker，可以跑 Qdrant
5. 有 JupyterLab + SSH，部署调试方便

### 选型检查清单（下单前必须确认）

| 检查项 | 必须满足 | 为什么 |
|--------|:--:|------|
| GPU 显存 ≥ 8GB | ✅ | BGE-M3 + Reranker 同时加载需要 |
| 内存 ≥ 16GB | ✅ | Qdrant + Python 进程 + 峰值计算 |
| 可安装 Docker | ✅ | Qdrant 需要容器运行 |
| 有公网 IP | ✅ | 前端需要公网访问 |
| 可开放端口（5173/8000/6333） | ✅ | 或至少可配 Nginx 反代 |
| CUDA ≥ 11.8 | ✅ | FlagEmbedding 依赖 |
| 出站网络可访问 api.deepseek.com | ✅ | LLM API 调用 |
| 入站网络可访问 HuggingFace | ✅ | 首次下载模型（或预上传） |

## 三、环境初始化（以 AutoDL + Ubuntu 为例）

```bash
# 1. 克隆项目
git clone git@github.com:zsy04/finance-rag-agent.git
cd finance-rag-agent

# 2. 安装 Docker + Qdrant
sudo apt update && sudo apt install -y docker.io docker-compose
sudo systemctl start docker
docker compose up -d
# 验证: curl http://localhost:6333/healthz

# 3. 创建 Python 虚拟环境
python3 -m venv backend/venv
source backend/venv/bin/activate
pip install -r requirements.txt

# 4. 设置环境变量
cat > backend/.env << 'EOF'
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
QDRANT_URL=http://localhost:6333
EOF

# 5. 上传模型文件（如果实例没有外网）
# 方案 A: 从 HuggingFace 直接下载（需设镜像）
export HF_ENDPOINT=https://hf-mirror.com
python -c "from FlagEmbedding import BGEM3FlagModel; BGEM3FlagModel('BAAI/bge-m3')"

# 方案 B: 从本地上传（预先打包好 ~5GB）
# 本地: tar -czf models.tar.gz ~/.cache/huggingface/hub/models--BAAI--bge-m3/
# scp models.tar.gz user@server:/path/to/

# 6. 嵌入数据到 Qdrant
cd scripts
python embed_and_upsert.py
# 等待 15-20 分钟（GPU 编码 2937 chunks）

# 7. 启动后端
cd ..
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 &
# 验证: curl http://localhost:8000/health

# 8. 构建前端 + 启动
cd frontend
npm install
npm run build
# dist/ 目录即为静态文件，用 Nginx 或 Python 静态服务器托管
```

## 四、生产化部署架构

```
用户浏览器
    │
    ▼
┌─────────┐    反向代理     ┌──────────┐    API 调用    ┌──────────────┐
│  Nginx  │ ──────────────→ │ FastAPI  │ ────────────→ │ DeepSeek API │
│ :80/443 │ ←────────────── │ :8000    │               │ (公网)       │
│         │                 │          │               └──────────────┘
│ 托管前端 │                 │ Agent    │
│ dist/    │                 │ + RAG    │
└─────────┘                 │ + Tools  │
                             └────┬─────┘
                                  │ gRPC
                                  ▼
                           ┌──────────┐
                           │ Qdrant   │
                           │ :6333    │
                           │ (Docker) │
                           └──────────┘
```

### Nginx 配置模板

```nginx
server {
    listen 80;
    server_name your-domain.com;  # 或公网 IP

    # 前端静态文件
    root /path/to/finance-rag-agent/frontend/dist;
    index index.html;

    # SPA 路由（React Router）
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 代理 → FastAPI 后端（SSE 需要特殊配置）
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Connection '';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_buffering off;          # SSE 必须关闭缓冲
        proxy_cache off;
        proxy_read_timeout 300s;      # SSE 长连接
    }

    # 图标/静态资源
    location /icons/ {
        alias /path/to/finance-rag-agent/frontend/public/icons/;
        expires 30d;
    }
}
```

## 六、成本优化技巧

| 技巧 | 省多少 | 怎么做 |
|------|:--:|------|
| **竞价/抢占实例** | 50-70% | 阿里云/腾讯云选择"竞价实例"，价格是包月的 1/3 |
| **按时段启停** | 80% | 答辩前后 3 天租用，平时关机不收费（仅收磁盘费 ~¥0.5/天） |
| **模型预缓存** | 无 | 模型文件打包上传（~5GB），避免首次下载耗时长 |
| **Qdrant 数据预置** | 无 | 在本地跑好 embed_and_upsert.py，打包 qdrant_data/ 上传即可跳过嵌入步骤 |
| **前端 CDN** | 带宽 | 前端 dist/ 放 OSS + CDN，不占用服务器带宽 |

## 七、如果不用 GPU 服务器（备选）

**可以**，但检索会非常慢：

| 操作 | GPU 服务器 | CPU-only |
|------|:--:|:--:|
| BGE-M3 嵌入 2937 chunks | 15 分钟 | 2-3 小时 |
| 单次检索（dense+sparse+Reranker） | ~2 秒 | ~30 秒 |
| BGE-Reranker 精排 | ~0.5 秒 | ~8 秒 |

**如果坚持 CPU-only**：改用轻量模型（如 `all-MiniLM-L6-v2`），检索质量会明显下降。不推荐用于毕设答辩。

## 八、快速部署脚本（一键部署到 Ubuntu）

```bash
#!/bin/bash
# deploy.sh — 一键部署脚本（Ubuntu 22.04）
set -e

echo "========== 财税助手 · 一键部署 =========="

# 0. 环境检查
command -v docker >/dev/null || { echo "请先安装 Docker"; exit 1; }
command -v python3 >/dev/null || { echo "请先安装 Python 3.10+"; exit 1; }
command -v node >/dev/null || { echo "请先安装 Node.js 22+"; exit 1; }

# 1. 启动 Qdrant
echo "[1/6] 启动 Qdrant..."
docker compose up -d
sleep 3
curl -s http://localhost:6333/healthz > /dev/null || { echo "Qdrant 启动失败"; exit 1; }

# 2. Python 环境
echo "[2/6] 安装 Python 依赖..."
python3 -m venv backend/venv
source backend/venv/bin/activate
pip install -r requirements.txt -q

# 3. 环境变量（需手动填 DeepSeek Key）
if [ ! -f backend/.env ]; then
    read -p "请输入 DeepSeek API Key: " DS_KEY
    cat > backend/.env << EOF
DEEPSEEK_API_KEY=$DS_KEY
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
QDRANT_URL=http://localhost:6333
EOF
fi

# 4. 嵌入数据（如果 Qdrant 为空）
echo "[3/6] 检查向量数据..."
COLLECTION_EXISTS=$(curl -s http://localhost:6333/collections | grep -c "finance_knowledge" || true)
if [ "$COLLECTION_EXISTS" -eq 0 ]; then
    echo "嵌入数据中（约 15 分钟）..."
    cd scripts && python embed_and_upsert.py && cd ..
else
    echo "向量数据已存在，跳过嵌入"
fi

# 5. 启动后端
echo "[4/6] 启动后端..."
nohup python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 > backend.log 2>&1 &
sleep 5
curl -s http://localhost:8000/health > /dev/null || { echo "后端启动失败"; cat backend.log; exit 1; }

# 6. 构建前端
echo "[5/6] 构建前端..."
cd frontend && npm install -q && npm run build && cd ..

# 7. Nginx 配置
echo "[6/6] 配置 Nginx..."
sudo apt install -y nginx
sudo cp nginx.conf /etc/nginx/sites-available/finance-rag
sudo ln -sf /etc/nginx/sites-available/finance-rag /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

echo ""
echo "========== 部署完成 =========="
echo "访问: http://$(curl -s ifconfig.me)"
echo "后端日志: tail -f backend.log"
```
