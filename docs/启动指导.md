# 财务 RAG Agent · 启动指导

> 每次重新开机后，按以下步骤启动项目。

---

## 环境一览

| 服务 | 地址 | 说明 |
|------|------|------|
| 前端 (Vite) | `http://localhost:5173` | React 页面 |
| 后端 (FastAPI) | `http://localhost:8000` | Agent + RAG + SSE |
| Qdrant 向量库 | `http://localhost:6333` | 向量检索 Dashboard |
| Docker Desktop | — | Qdrant 容器依赖 |

---

## 启动步骤

### 第一步：启动 Docker + Qdrant

打开 **Docker Desktop**（桌面图标），等待左下角变绿（Engine running）。

然后：

```bash
cd F:/lest
docker compose up -d
```

验证：

```bash
curl http://localhost:6333/healthz
# 应返回: {"title":"qdrant - vector search engine","version":"1.18.3"}
```

> ⚠️ Qdrant 数据目录在 `F:/lest/qdrant_data/`，首次启动会自动创建 collection，后续启动数据都在。

---

### 第二步：启动后端

打开一个终端（PowerShell / Git Bash）：

```bash
cd F:/lest
F:/lest/backend/venv/Scripts/python.exe -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

验证：

```bash
curl http://localhost:8000/health
# 应返回: {"status":"ok"}
```

> 💡 后端启动约需 15-20 秒（加载 BGE-M3 和 Reranker 模型到 GPU）。

---

### 第三步：启动前端

打开另一个终端：

```bash
cd F:/lest/frontend
npm run dev
```

浏览器打开 `http://localhost:5173`，可以看到三视图界面。

> 如果 `npm run dev` 报找不到包，先运行 `npm install`。

---

## 一键启动脚本（可选）

保存为 `start.bat` 放在 `F:/lest/` 下，双击即可启动全部服务：

```batch
@echo off
echo ========== 财税助手 · 一键启动 ==========

echo [1/3] 启动 Qdrant...
docker compose up -d

echo [2/3] 启动后端 (8000)...
start "Backend" cmd /c "F:\lest\backend\venv\Scripts\python.exe -m uvicorn backend.main:app --host 0.0.0.0 --port 8000"

echo [3/3] 启动前端 (5173)...
start "Frontend" cmd /c "cd /d F:\lest\frontend && npm run dev"

echo.
echo ========== 全部启动完成 ==========
echo 前端: http://localhost:5173
echo 后端: http://localhost:8000
echo Qdrant: http://localhost:6333
echo.
pause
```

## 常见问题

| 问题 | 解决 |
|------|------|
| `curl: connection refused` | 对应服务未启动，检查那一步是否执行 |
| `docker compose` 报错 | Docker Desktop 没开，打开后等它变绿 |
| 后端启动报 `CUDA out of memory` | 关掉其他占 GPU 的程序（浏览器 GPU 加速等） |
| `ModuleNotFoundError: No module named 'xxx'` | 运行 `F:/lest/backend/venv/Scripts/pip install -r F:/lest/requirements.txt` |
| `HF_HUB_OFFLINE=1` 相关报错 | 模型文件缺失，先联网下载一次 HuggingFace 模型 |
| 前端发消息报"网络请求失败" | 后端没启动，或后端端口不是 8000 |
| Qdrant 数据丢失（6333 打开 collection 为空） | 运行重嵌入脚本：`cd F:/lest && python scripts/embed_and_upsert.py` |
