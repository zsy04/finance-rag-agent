# 财税法律 Markdown 格式规范

> 基于车船税法、烟叶税法、印花税法、增值税法四个文件的格式总结。
> 所有 `processed/national/tax_law/` 下的 `.md` 文件都应遵循此规范。

---

## 1. 文件结构总览

```
---
（YAML frontmatter）
---

# 法律全称

## 注释

（修正历史，一段或多段）

（如有目录，见下方 2.4）

## 第X条　（正文）

...

## 附：（如有附件）

附件文件名
```

---

## 2. 逐项规范

### 2.1 YAML Frontmatter

首尾各一行 `---`，中间字段无特殊要求，至少包含 `doc_title` 和 `category`。

```yaml
---
source_url: https://fgk.chinatax.gov.cn/...
doc_number: 主席令第X号
effective_from:
expiry_date:
module: 一
category: tax_law
city: national
doc_title: 印花税法
cleaned_at: 2026-07-27 17:08:42
---
```

**规则**：frontmatter 结束后空一行再开始正文。

---

### 2.2 法律标题

```markdown
# 中华人民共和国印花税法
```

- H1（一个 `#`），法律全称。
- 不是"印花税法"而是"中华人民共和国印花税法"。
- 标题后空一行。

> 例外：非"法"类文件（如"关于惩治虚开……的决定"）标题用原完整名称，不加"中华人民共和国"前缀。

---

### 2.3 注释（修正历史）

```markdown
## 注释

2021年6月10日第十三届全国人民代表大会常务委员会第二十九次会议通过
```

- `## 注释` 为 H2。
- 下一行为通过/修正日期，一段文字，不拆行。
- 如果有多条修正记录，用全角空格 `　` 分隔。
- 注释节后空一行。

---

### 2.4 目录（如有）

```markdown
## 目录

第一章　总　　则

第二章　税　　率

...
```

- `## 目录` 为 H2。
- 目录列为普通段落文本，不加序号。
- 章名使用全角空格 `　` 分隔，不加 `## `。
- 目录节后空一行。

---

### 2.5 章标题（如有）

```markdown
## 第一章　总　　则
```

- `## 第X章　XXX` 为 H2。
- 章名中的空格用 `　`（全角空格 U+3000）。
- 章标题后空一行。

### 2.6 节标题（如有）

```markdown
### 第一节　纳税人
```

- `### 第X节　XXX` 为 H3。
- 节标题末尾带全角空格。
- 节标题后空一行。
- 章 → 节 → 条的层级为：H2 章、H3 节、H2 条。

---

### 2.7 条（法律条文）

#### 格式 A：条标题 + 正文分两行

```markdown
## 第一条　

在中华人民共和国境内书立应税凭证、进行证券交易的单位和个人，为印花税的纳税人...
```

- `## 第X条　` 为 H2（末尾带全角空格）。
- 正文从下一行开始，普通段落。

#### 格式 B：条标题 + 正文同行（仅当条文字数少时）

```markdown
## 第四条　烟叶税的税率为百分之二十。
```

- 条标题后直接跟正文，中间用全角空格。

**选择规则**：正文超过 50 字用格式 A，少于 50 字可用格式 B。同文件内保持一致。

**层级关系**：无论条文处于章还是节之下，`第X条` 始终用 `##`（H2）。章 H2 → 节 H3 → 条 H2，节的存在不改变条的层级。

---

### 2.8 条内列表

**错误写法**（不要用 H3 子标题）：

```markdown
### （一）工资、薪金所得；     ← 错误
```

**正确写法**（用数字序号）：

```markdown
## 第三条　下列车船免征车船税：

1. 捕捞、养殖渔船；

2. 军队、武装警察部队专用的车船；

3. 警用车船；
```

- 用 `1. 2. 3.` 数字列表，不用 `（一）（二）（三）` 中文序号。
- 每个列表项独立一行，中间空行。
- 列表前不空行（紧跟条标题内容），列表后空一行。

---

### 2.9 段落间距

- **条与条之间**：`## 第X条` 前应有一个空行。
- **条内段落之间**：空一行。
- **章与节之间**：章标题后空一行，章内第一条前不额外空行。

---

### 2.10 附件

```markdown
## 附件：

印花税税目税率表.ppt
```

或简写：

```markdown
## 附：

车船税税目税额表.doc
```

- `## 附件：` 或 `## 附：` 为 H2。
- 下一行为附件文件名。

---

## 3. 禁止项

| ❌ 不要 | ✅ 应该 |
|---------|--------|
| `### （一）...` 作为子标题 | `1. 2. 3.` 数字列表 |
| `（一）（二）` 中文序号 | `1. 2. 3.` |
| `第一条` 无空格无 `##` | `## 第一条　` |
| 正文与条标题同行但超 50 字 | 正文换下一行 |
| 导航文字（字体大小、微信分享等） | 已在前序清洗中移除 |
| `### 中华人民共和国...` | `# 中华人民共和国...` |

---

## 4. 快速检查清单

- [ ] frontmatter 有 `doc_title` 和 `category`
- [ ] `# 标题` 为完整的"中华人民共和国XXX法"
- [ ] `## 注释` 后跟修正历史
- [ ] `## 第X条　` 全部为 H2，末尾有全角空格
- [ ] 条内列表用 `1. 2. 3.`，不用 `（一）（二）`
- [ ] 条与条之间有空行
- [ ] 无导航噪音、无 `###` 子标题
- [ ] 附件用 `## 附件：`
